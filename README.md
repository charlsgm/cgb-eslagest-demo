# EslaGest Cloud · demo

Versión compilada de la demo web de EslaGest Cloud (CGB Informática), publicada en GitHub Pages:
**https://charlsgm.github.io/cgb-eslagest-demo/**

## Prototipos y nuevas interfaces
- **Modern SaaS / Linear UI**: [`prototipos/modern.html`](https://charlsgm.github.io/cgb-eslagest-demo/prototipos/modern.html)
- **Comparativa de mockups**: [`mockups/index.html`](https://charlsgm.github.io/cgb-eslagest-demo/mockups/index.html)
- **Prototipo Asistente IA original**: [`prototipos/asistente.html`](https://charlsgm.github.io/cgb-eslagest-demo/prototipos/asistente.html)
- **Página de inicio de sesión**: [`mockups/login.html`](https://charlsgm.github.io/cgb-eslagest-demo/mockups/login.html)

Funciona sin servidor: los datos son ficticios y se guardan en el navegador. Usuarios de prueba (contraseña `demo`):
`gerencia@grupoesla.es`, `comercial@distribucionesesla.es` y `soporte@cgbinformatica.es` (superadmin).

El código fuente está en el repositorio privado `cgb-eslagest`; este repositorio solo contiene la web compilada.
